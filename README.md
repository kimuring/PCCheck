# PC Check

Windows PC の状態（ハードウェア・セキュリティ・リソース使用状況）を 1 つの画面で確認できるツールです。
exe をダブルクリックするだけで動作し、インストールや管理者権限は不要です。

## 作成の背景

SES として常駐した現場で、Windows Server 約 30 台にリモートデスクトップで 1 台ずつ接続し、
IP アドレス・死活状況・ウイルス対策ソフトが規定バージョン以上かどうかを目視で確認し、Excel の管理表に記録していました。

この「人が画面を見て確認していた作業」をツールで一括確認できるようにしたいと考え、
まずは 1 台の PC の状態を一目で把握し、結果をそのまま報告・記録に使えるツールとして作成しました。

## 主な機能

| タブ | 内容 |
|---|---|
| 概要 | OS / CPU / メモリ（規格・スロット）/ GPU / マザーボード・BIOS / ストレージ（SSD・HDD）/ ネットワーク |
| リアルタイム | CPU・メモリ使用率のグラフ（直近 60 秒）、CPU・メモリを多く使っているプロセス TOP15 |
| セキュリティ | ウイルス対策ソフト（他社製を含む）の状態・バージョン、Microsoft Defender の定義ファイル、Windows Update の適用状況 |

- **自動判定**：問題がある項目を「要対応」「注意」で色分けし、画面上部にバッジで件数を表示
- **レポートをコピー**：PC の情報をテキストでクリップボードへ。ヘルプデスクへの問い合わせにそのまま貼り付け可能
- **CSV で保存**：Excel でそのまま開ける形式（BOM 付き UTF-8）で保存
- **表示言語の切り替え**：メニュー「設定 → 表示言語」から日本語 / 韓国語を選択（次回起動時も保持）

## 判定基準

| 項目 | 注意 | 要対応 |
|---|---|---|
| セキュリティソフト | 状態を確認できない | 有効なソフトがない |
| ウイルス定義ファイル | 3 日以上更新なし | 7 日以上更新なし / ソフトが「古い」と報告 |
| リアルタイム保護（Defender） | － | 無効 |
| Windows Update | 35 日以上適用なし / 履歴を確認できない | 60 日以上適用なし |
| ディスク空き容量 | 20% 未満 | 10% 未満 |
| 再起動 | 14 日以上再起動なし（高速スタートアップが有効な場合は、シャットダウンではリセットされない旨も表示） | － |

基準値は `src/RowBuilder.cs` の先頭で定義しています。

## 動作環境

- Windows 10 / 11
- .NET Framework 4.5 以上（Windows 10 / 11 には標準で搭載）
- 管理者権限：不要
- ※ Windows Server では「Windows セキュリティセンター」の情報を取得できないため、一部の項目が「確認できません」になります

## 使い方

1. [Releases](../../releases) から zip をダウンロードして展開
2. `PCCheck.exe` をダブルクリック
3. 初回起動時に「Windows によって PC が保護されました」と表示された場合は「詳細情報」→「実行」を選択
   （コード署名をしていない個人制作のツールのため表示されます）

## 技術的なポイント

- **ハードウェア情報**：WMI（`Win32_OperatingSystem`、`Win32_Processor`、`Win32_PhysicalMemory`、`MSFT_PhysicalDisk` など）から取得
- **ウイルス対策ソフト**：`root\SecurityCenter2` の `AntiVirusProduct` から、他社製を含むソフトの有効/無効と定義ファイルの状態を `productState` のビットを解析して判定
- **Defender の詳細**：`MSFT_MpComputerStatus` からバージョン・定義ファイル更新日時・リアルタイム保護の状態を取得
- **Windows Update**：Windows Update Agent API（COM）で更新履歴を取得し、毎日配信される Defender 定義ファイルの更新を除外して「最後に OS の更新を適用した日」を算出。取得できない場合は `Win32_QuickFixEngineering` で代替
- **リアルタイム監視**：CPU 使用率は `GetSystemTimes`、メモリは `GlobalMemoryStatusEx`（Win32 API）で 1 秒ごとに計測
- **プロセス一覧**：タスクマネージャーと同じ `NtQuerySystemInformation` で全プロセスの CPU 時間とメモリをまとめて取得。プロセスを 1 つずつ開かないため、管理者権限がなくてもサービスやセキュリティソフトなど SYSTEM で動くプロセスも集計できる（v1.0.1 までは権限のないプロセスが 0% と表示されていた）
- **画面が固まらない設計**：時間のかかる情報収集は別スレッド（`async` / `await`）で実行
- **データと表示の分離**：取得したデータと画面表示を分けているため、言語を切り替えても再取得せず表示だけを更新
- **多言語対応**：画面の文字列を `Lang.cs` に集約し、キーで呼び出す仕組み

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/Program.cs` | 起動処理 |
| `src/MainForm.cs` | 画面（タブ・メニュー・ボタン）と表示処理 |
| `src/Collector.cs` | WMI・Win32 API による情報収集 |
| `src/RowBuilder.cs` | 表示用の行の作成と判定ロジック |
| `src/Report.cs` | レポート（テキスト）と CSV の作成 |
| `src/Lang.cs` | 日本語・韓国語の文字列と設定の保存 |
| `src/GraphPanel.cs` | 使用率グラフの描画 |
| `src/Models.cs` | データの入れ物と書式 |
| `src/Native.cs` | Windows API の宣言 |

## ビルド方法

Visual Studio 2022 で `src/PCCheck.csproj` を開いてビルドするか、以下を実行します。

```
cd src
dotnet build -c Release
```
